# Backend

The backend provides typed local media inspection, deterministic FFmpeg anomaly detectors, creator publishing-package rules, SRT/WebVTT caption inspection, an explainable unified report, a CLI, and FastAPI endpoints.

FFprobe is required for inspection and FFmpeg is required for detector execution and test-fixture generation. The test suite creates synthetic MP4 files in pytest-managed temporary directories; no media is downloaded or committed. The Milestone 2 fixture is generated by `_generate_anomaly_video` in `tests/conftest.py` and contains these known intervals:

- near-black video from 2 to 5 seconds;
- silent audio from 3 to 6 seconds;
- a non-black static video section from 7 to 10 seconds;
- near-full-scale audio from 10 to 11 seconds for the global peak measurement.

`PreflightScanner` is the shared service used by CLI and API. It inspects media once, runs applicable detector passes, evaluates package rules, reconciles black-contained freeze findings, records explicit check outcomes, and calculates the report verdict directly from normalized findings.

Chapter parsing recognizes only description lines that begin with `MM:SS` or `H:MM:SS`, followed by whitespace and a nonempty chapter name. Other numbers and inline time-like text are ignored. URL validation is syntax-only and never uses the network.

Run the backend tests from the repository root:

```sh
.venv/bin/python -m pytest backend/tests
```

CLI usage:

```sh
releaseseal scan VIDEO_PATH --title "Title" --description-file description.txt
releaseseal scan VIDEO_PATH --title "Title" --description "Text" --json
```

Optional scan arguments are `--captions`, `--config`, and `--json`. `--description` and `--description-file` are mutually exclusive. Exit codes are:

- `0`: scan completed with verdict `READY`;
- `1`: scan completed with verdict `NEEDS_REVIEW` or `BLOCKED`;
- `2`: invocation, configuration, input, dependency, or runtime failure.

API endpoints:

- `POST /api/v1/media/inspect` preserves the Milestone 1 metadata-only upload behavior.
- `POST /api/v1/preflight/scan` accepts multipart `file`, `title`, `description`, and optional `captions` fields and returns `PreflightReport`.

Run the local API from the repository root:

```sh
.venv/bin/uvicorn releaseseal.api:app --app-dir backend/src --reload --host 127.0.0.1 --port 8000
```

Uploaded media and caption handles are request-scoped. Media is copied into a temporary directory for scanning, then closed and removed after either a successful report or an error response.

Caption inspection accepts UTF-8 SRT and WebVTT content and does not trust the filename extension alone. It validates cue syntax, start/end order, media-duration bounds, file order, meaningful overlaps, empty text, and configurable long gaps. `caption_summary` reports cue count and merged timeline coverage, so overlapping cues cannot push coverage over 100%. Gaps and overlaps remain review evidence because music, silence, stills, and deliberate multi-speaker captions are legitimate.

Local speech/caption comparison is optional:

```sh
.venv/bin/python -m pip install './backend[transcription]'
```

Enable it with the YAML `transcription.enabled` setting. `faster-whisper` is imported and its model loaded lazily; compatible models are cached within the backend process. CPU is supported and is the default. `local_files_only: true` prevents an implicit model download. If the dependency or model is unavailable, or transcription fails, the deterministic scan completes with a structured review finding. No cloud speech service is used.
